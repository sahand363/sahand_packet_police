# Traffic Camouflage Inspector 🛡️

A real-time packet sniffer and Traffic Camouflage Inspector dashboard built with Python and Streamlit. Designed to monitor raw TCP ports vs. WebSocket-camouflaged ports.

## Installation & Auto-Setup

Run the following commands on your Linux server:

```bash
git clone [https://github.com/sahand333/sahand_packet_police.git](https://github.com/sahand333/sahand_packet_police.git)
cd sahand_packet_police
chmod +x setup.sh
sudo ./setup.sh
